# deepslate-worldgen-mods

Deepslate compatibility patches and custom density function implementations for popular Minecraft world generation mods.

## Supported Mods

#### Worldgen Libraries

- **[More Density Functions](https://github.com/klinbee/More-Density-Functions)** (@klinbee)
- **[Lithostitched](https://github.com/Apollounknowndev/lithostitched)** (@Apollounknowndev)
- **[ikbLib](https://github.com/ikkyblob/ikbLib)** (@ikkyblob)
- **[En-sityFunctions](https://modrinth.com/mod/en-sityfunction)** (MikeStorm03) 

#### Worldgen Projects

- **[Tectonic](https://modrinth.com/datapack/tectonic)** (@Apollounknowndev)

## Declaration of AI-use
<h3>Almost all implementations in this repository were created by generative AI in an agentic process.</h3>
<h6>Although I am a strong advocate of reserving certain processes in programming for humans.</h6>

Here is why I think that is okay:
1. **The implementation methods are already clear.** We simply need to mirror the behavior of the mods in Java to TypeScript. This process does not require a special form of creativity (which I would normally like to be performed by a human).
2. While such a porting does not require creativity **it still can be very exhausting** - because of the sheer amount of code or its complexity or because it contains a lot finely tuned details that can lead to accidental errors during the transfer.

**But of course, all contributions from humans are very welcome too.**
