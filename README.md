# deepslate-worldgen-mods

Deepslate compatibility patches and custom density function implementations for popular Minecraft world generation mods.

## Supported Mods

- **[More Density Functions](#)** (Klinbee)
- **[Lithostitched](#)** (Apollo)
- **[En-sityFunctions](#)** 
- **[Tectonic](#)** (Apollo)

## Declaration of AI-use
<h3>Almost all implementations in this repository were created by generative AI in an agentic process.</h3>
<h6>... Although I am a strong advocate of reserving certain processes in programming for humans.</h6>

Here is why I think that is okay:
1. **The implementation methods are already clear.** We simply need to mirror the behavior of the mods in Java to TypeScript. This process is cognitively easy and does not require a special form of creativity (which I would normally like to be performed by a human).
2. Translating the worldgen features of *some* mods is simply ***a lot* of monotonous work**.
